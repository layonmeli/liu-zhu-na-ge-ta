# 欲言 · 完整版使用说明

陪你说出，心里那一句。

「欲言」陪你从没说清的话、聊天片段、行动和回忆里，找到自己真正想表达的意思，再整理成自己说得出口的话。可以用于朋友、恋人、家人或其他重要关系中的感谢、想念、歉意、委屈、边界、修复与告别。也可以只理清自己、得到一点鼓励，或把话留着不发。

**直接开始**

中文名称是「欲言」，调用名仍是 `$liu-zhu-na-ge-ta`。在已安装并支持 Skill 的对话环境里，可以这样开口：

> 使用 $liu-zhu-na-ge-ta。我有些想对一个人说的话，但自己也没想清楚。先陪我梳理，不用急着写成稿。

不用先做问卷。你可以贴自己的半句话、一小段聊天，讲一件记得的小事，或描述一张照片、一个旧物。关系、这次想做什么、希望什么语气，只需说明与你这次表达有关的部分。截图、图片和语音能否直接读取取决于当前环境；读不到时，用几句话描述也能开始。

**按你这次的需要使用**

| 你现在需要什么 | 可以直接这样说 |
| --- | --- |
| 还不知道自己想说什么 | “我说了‘算了，你忙吧’，但自己也不清楚是什么意思。先帮我理清，每轮只问一个问题。” |
| 知道意思，想写出来 | “妈妈今天又给我留了饭，我想告诉她我记在心里。写一条日常的微信，只给文案。” |
| 先讲完，不想被打断 | “我会分几次发材料，等我说发完了再整理。” |
| 只想弄懂自己 | “先帮我总结我在意的是什么，暂时不写给对方，也不打算发送。” |
| 不确定对方态度 | “我不知道他怎么想，但我确定想感谢那次帮助。别猜他的动机，帮我说清自己的意思。” |
| 只需一点鼓励 | “稿子已经写好，先别改，也别分析原因，只给我一句有依据的鼓励。” |
| 有情绪，仍想说清边界 | “我还很难过，但知道想说什么。帮我说清这件事不能继续，别替我撤回这个意思。” |
| 不想披露所有细节 | “我想真诚地拒绝这次邀请，但家里的原因不想讲，帮我保留这个范围。” |
| 想修改自己的草稿 | “别重写整篇，告诉我哪一句容易被误解，只改最必要的一处。” |
| 想复盘真实回应 | “这是我发的话和对方的回复。帮我分清已经说清的部分、还没确定的部分，不猜对方内心。” |

默认通常给一版适合场景的短表达；你可以指定一句话、微信、语音稿、信、当面开场或照片旁注。你已经说清意思时，它应直接帮助，不要求走完整套流程。随时可以说“先停”“今天不发”或“先听就好”。

**怎样让表达更像你**

给一两句你自己平时会说的话，或者直接指出：

- “这句像我，这个词我不会用。”
- “我不是怕麻烦他，我是还没想好要什么。”
- “这个版本太客气了，我想更直接。”
- “感谢是真的，但我不想答应以后每次都帮忙。”

你的修正优先于它的猜测。真诚允许含蓄、矛盾和不确定：既要像你的语气，也要准确表达你的意思，承诺你确实愿意承担的事。没有发生的经历、没产生的情绪或对方没说过的心意，不应为了文案动人而补进去。

**开启个人化，让以后少重复解释**

你可以说：

> 开启个人记忆。以后逐渐了解我的表达和支持偏好；我明确纠正你的时候，也请更新原来的理解。

开启后，它会在使用「欲言」时提炼少量有用摘要，例如你给家人说话的语气、紧张时希望怎样被支持、本人明确在意的事及仍有用的具体情境。没有新信息就不必更新。拿不准的理解保留为待核对项，并设置期限；不会把一时情绪当成永久性格。

个人记忆是一份与技能包分开的本地文件，默认在当前系统用户目录下的 `.yuyan/memory.json`。持续读写需要运行环境提供本地文件能力和 Python 3.9+；普通梳理与写作不依赖开启记忆。安装文件本身不会后台运行，个人资料不会随这个技能包一起分享。本工具通过读取相关摘要实现个性化，不执行模型训练或自动跨设备同步。

该文件未单独加密；实际用于回应的摘要会进入当前模型上下文。它只处理你提供或授权的材料，不自动翻找其他聊天、相册或账号。使用共享设备或换使用者时，应先暂停旧个人化或明确切换独立资料位置。

**你始终能控制记录**

| 你说 | 会发生什么 |
| --- | --- |
| “你记住了我什么？” | 查看内容、适用情境和确认状态；暂停时也可以主动查看 |
| “这条理解错了，真实意思是……” | 更正相应理解，清理由错误推断派生的概括 |
| “这段别记。” | 这段不保存；不会自动删除以前的记录 |
| “暂停个人化。” | 停止自动使用和新增记忆，保留已有资料供查看或删除 |
| “恢复个人化。” | 按你的要求重新开启，使用仍有效的记录 |
| “忘记这条／关于某人的事。” | 删除指定范围的记录及相关摘要 |
| “清空个人记忆，先别再记。” | 清空本知识库并停用；聊天平台历史、其他文件和你自行备份不在这次操作范围内 |

工具没有成功执行时，它应说明尚未完成，不能仅凭回复“记住了”就算已经保存。

**这份工具的边界**

它帮助你整理和表达，不替你认定别人真实的想法、诊断人格或保证对方回应、原谅、复合。别人明确拒绝联系时，可以写给自己或处理已有约定的必要事务，不能用“表达真诚”绕过边界。存在现实威胁或危险时，先处理安全需要。

生成草稿不等于代为发送。你可以继续修改、选择不说、暂停或保留一部分隐私；这些都可以是完整的使用结果。
